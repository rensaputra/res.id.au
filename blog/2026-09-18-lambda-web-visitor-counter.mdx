Built a high-performance, strongly typed AWS Lambda function backed by Amazon DynamoDB for atomic web visitor counting, triggered via Amazon API Gateway HTTP API (Payload v2).

## What Was Built

### 1. Source Architecture
- [`src/types.ts`](https://github.com/rensaputra/visitor-counter-api/blob/d180e02969a307162b1cab1ee1589d10396f2bd8/src/types.ts): Strongly typed models for `CounterRecord`, `CounterResponse`, `ErrorResponse`, and `AppConfig`.
- [`src/config.ts`](https://github.com/rensaputra/visitor-counter-api/blob/d180e02969a307162b1cab1ee1589d10396f2bd8/src/config.ts): Environment variable loader for `TABLE_NAME`, `ALLOW_ORIGIN`, `DEFAULT_PAGE_ID`, and `AWS_REGION`.
- [`src/utils.ts`](https://github.com/rensaputra/visitor-counter-api/blob/d180e02969a307162b1cab1ee1589d10396f2bd8/src/utils.ts): CORS headers, API Gateway v2 response builders, and `pageId` sanitization (validates characters and restricts max length to 128 characters).
- [`src/counter.ts`](https://github.com/rensaputra/visitor-counter-api/blob/d180e02969a307162b1cab1ee1589d10396f2bd8/src/counter.ts): DynamoDB atomic operations using AWS SDK v3 `DynamoDBDocumentClient`:
  - `incrementCounter`: Uses atomic update expression:
    ```typescript
    SET #count = if_not_exists(#count, :zero) + :inc, #updatedAt = :now
    ```
  - `getCounter`: Reads count without incrementing; returns `{ count: 0, updatedAt: null }` for unvisited pages.
- [`src/handler.ts`](https://github.com/rensaputra/visitor-counter-api/blob/d180e02969a307162b1cab1ee1589d10396f2bd8/src/handler.ts): Main AWS Lambda handler (`APIGatewayProxyHandlerV2`):
  - Handles `OPTIONS` CORS preflight requests (HTTP 204).
  - Routes `POST` to increment counter.
  - Routes `GET` to read counter.
  - Returns HTTP 405 for unsupported HTTP methods.
  - Returns HTTP 400 for malformed input or invalid `pageId`.
  - Returns HTTP 500 for missing config or database errors.
