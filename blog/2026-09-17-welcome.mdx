### Docusaurus Blog Features Summary

This blog is powered by Docusaurus, which provides several great features out-of-the-box:

- **MDX Support**: Blog posts support Docusaurus Markdown features, such as MDX. This allows the use of React components (like interactive buttons) and Admonitions (callouts/tips) directly inside the markdown files.
- **Truncation**: The `{/* truncate */}` comment can be used to limit the blog post size in the list view, keeping the main blog page clean and readable.
- **File Organization**: Posts can be standalone markdown files or placed within their own folders, which is convenient for co-locating images specific to a post.
- **Metadata**: The blog post date can be automatically extracted from filenames (e.g., `2026-09-17-welcome.mdx`), and author/tag metadata is easily managed via `authors.yml` and `tags.yml`.
